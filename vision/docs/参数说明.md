# 参数说明

## 常用参数

- `--camera-index`：Windows 摄像头编号，默认 `0`。如果外接摄像头打不开，可以尝试 `1`、`2`。
- `--face-weights`：YOLO5Face 权重路径，默认 `yolov5-face/weights/yolov5s-face.pt`。
- `--device`：推理设备。留空自动选择 CUDA 或 CPU；CPU 可以运行但速度较慢。
- `--img-size`：YOLO 输入尺寸，默认 `640`。
- `--face-conf`：人脸检测置信度阈值，默认 `0.4`。
- `--iou-thres`：NMS 阈值，默认 `0.5`。
- `--crop-margin`：在人脸框外扩多少再送入 EmotiEffLib，默认 `0.30`。
- `--sample-step`：每隔多少帧完整检测一次，默认 `3`。数值越大越省算力，但画面响应更慢。
- `--save-output`：可选，传入路径时保存检测视频。

## 画面颜色

- 绿色框：YOLO5Face 原始人脸检测框。
- 黄色框：实际送入 EmotiEffLib 分类器的 crop 框。

标签格式为：

```text
happy 0.82 face:0.91
```

其中 `happy` 是表情类别，`0.82` 是表情置信度，`face:0.91` 是人脸检测置信度。
