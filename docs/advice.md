# 任务：在现有视觉识别链路上，做一个家长端陪护仪表盘

## 现状（已经跑通，不要动这部分）

系统链路：Jetson(摄像头/底盘) → VM 上传帧到 AutoDL → AutoDL 做情绪识别+物体识别 →
结果写回 VM 本地两份 JSON → RoboEyes 读情绪、AI语音节点读情绪做对话。

VM 上现有的可复用资源：

- 视觉识别结果 API：`http://127.0.0.1:8090/vision/latest`（`vision_result_api.py` 提供），
  内容大致是 `timestamp / face_count / dominant_emotion / confidence / scores(各情绪概率) / object_count / objects(class+confidence列表)`，
  但这个接口**只返回最新一帧的快照，没有历史**。
- 已有一个简单前端目录 `~/yolov5_emotieff_vgaf_windows/frontend`，用 `python3 -m http.server 9000` 起服务，
  里面已经有 `vision_dashboard.html`（现在应该是实时展示当前情绪/物体的页面）。
- 语音对话在 `robot_voice` 的 `ai_companion_dialogue.launch` 里跑，负责 TTS 回复和融合情绪做出反应，
  但目前应该没有把对话内容持久化成日志（需要确认，没有就加）。

## 要做的事

在不改动上面识别链路的前提下，加一层"记录+展示"，目标是让家长能看到：

1. **情绪曲线**：把 `/vision/latest` 按一定频率（比如每秒或几秒）轮询采样，落成一份带时间戳的历史记录（本地文件或 SQLite 都行，选你觉得简单可靠的），才能画出一天的情绪走势图，而不是只看"此刻"。
2. **今日学习记录**：同样从 `objects` 字段里提取识别到的物体，作为孩子今天"接触/学习"到的概念记录下来（去重、按首次出现时间记一条即可）。
3. **聊天记录**：需要给语音对话节点补一个"把每一轮说的话记下来"的动作（对话文本 + 时间戳 + 说话方是孩子还是机器人），具体挂载点你看 `ai_companion_dialogue.launch` 和 `robot_voice` 目录下的脚本，找到回复生成/播报的位置加日志即可，格式自定。
4. **家长端网页**：在现有 `frontend` 目录基础上新增一个面向家长的页面（不用推翻 `vision_dashboard.html`，可以并存），展示：今天的情绪曲线、聊天记录时间线（两者最好能联动，点情绪曲线上的点跳到对应时间的对话）、今日学习到的概念列表、以及一段"最近情绪趋势"的简单总结。

## 一个重要的产品原则（务必遵守）

情绪趋势这块只能是**描述性的**（比如"今天情绪整体比较平稳/今天情绪波动较大"），不能出现"心理健康评分""诊断"之类的说法，也不要暗示这是医学结论。如果观察到持续的负面趋势，界面上的建议应该是"建议家长多关注、必要时找专业人士"，而不是自己下结论。这是儿童产品的红线，其他实现细节你可以自由发挥。
